# CGPA Calculator (C++)

A console program that calculates semester GPA and overall CGPA. Built as Task 1 of the CodeAlpha C++ Programming Internship.

## Features
- Enter student name, roll number, course titles, grades and credit hours
- Calculates semester GPA and overall CGPA
- Saves every calculation to records.txt using file handling
- View previous calculations from the menu

## Concepts Used
- Object-Oriented Programming (classes and encapsulation)
- File handling
- Vectors and functions

## How to Run
Open all the files in Visual Studio, build the project, and run it.
